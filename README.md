## 🌟 主要功能概述

### 1. 介面與顯示最佳化
* **動態收合設定區：** 點擊「收起設定區」按鈕，下方的地圖預覽區會自動往下延伸放大，提供最大化的編輯空間。
* **全域字體與滾輪調整：** 支援即時調整字體大小（12px - 28px），並可在字體控制區滾動滑鼠滾輪快速縮放。
* **精簡工具列：** 提供「檢視平移」、「框選新增」、「編輯圖塊」、「刪除圖塊」等快捷模式，介面簡潔不擁擠。
* **畫布自由縮放：** 支援滑鼠滾輪、拉桿或精準的 `[-]` / `[+]` 按鈕進行畫布縮放與重置。

### 2. 檔案與圖庫管理
* **大地圖上傳：** 支援上傳任意尺寸的大型地圖圖片進行即時像素解析。
* **智慧關鍵字批次上傳小圖案：** 支援批次上傳多個圖塊小圖案，並依據檔名內建的**智慧關鍵字規則**自動對應圖塊屬性（如藍格、紅格、黃格、卡片賣場等）。
* **線上圖庫與匯入導出：** 內建多個線上預設圖庫包快速載入，並支援圖庫與自定義關鍵字的 `.json` 檔案匯入與導出。

### 3. 自動辨識與網格編碼
* **一鍵自動辨識：** 自動掃描地圖與圖庫進行比對，並依據 **Y 軸向上** 的規則建立標準網格座標系統。
* **多圖層獨立篩選：** 可依圖塊屬性過濾檢視，並自由勾選顯示/隱藏 **外框**、**屬性** 與 **座標** 圖層。

### 4. 互動編輯與框選新增
* **框選新增（含前三候選推薦）：** 支援降至 0.6 相似度門檻，框選後自動跳出視窗列出**前三大熱門匹配候選**，點擊即可手動切換並自動完成周遭節點的 **+1 座標推擠**。
* **圖塊點擊編輯：** 支援直接修改節點的中英文名稱、日文站名或更改圖塊屬性類型。
* **圖塊刪除與同步推擠：** 點擊刪除後，系統會自動更新周邊網格座標。

### 5. 數據導出
* **一鍵複製與下載：** 將編輯完成的地圖數據（包含區域、節點座標、屬性、名稱與連線）一 keV 複製到剪貼簿或直接下載為 `.json` 檔案。
* **全部重來：** 提供一鍵重置功能，可隨時清空狀態回到初始介面。

## 🚀 快速使用指南

1. **取得程式碼：** 將專案下載或直接將 `index.html`（與對應的圖庫檔案）儲存至您的電腦。
2. **開啟編輯器：** 直接用任何現代網頁瀏覽器（Chrome、Edge、Firefox 等）雙擊開啟 `index.html` 即可使用，無需安裝任何額外環境。
3. **步驟操作：**
   * **步驟一：** 點擊上傳您的**大地圖圖片**。
   * **步驟二：** 上傳對應的小圖案（或從上方選擇**線上圖庫包**）。
   * **步驟三：** 點擊 **「執行自動辨識與網格編碼」**，系統會自動標出網格。
   * **步驟四：** 利用工具列切換至「框選新增」、「編輯圖塊」或「刪除圖塊」來手動修正地圖細節。
   * **步驟五：** 點擊 **「複製 JSON」** 或 **「下載 JSON」** 導出您的地圖數據！
