## 🗺️ 專案功能特色

### 1. 📂 圖庫動態切換與備份管理
* **線上圖庫下拉選單**：支援直接在網頁上選擇並載入多個預設的圖庫包（如 `templates_1.json`、`templates_2.json`、`templates_3.json`）。
* **本地匯入 / 匯出**：可將自己調整好的圖庫包匯出成 JSON 備份，或隨時從電腦選擇自訂的 JSON 圖庫進行匯入。

### 2. 📦 智慧批次小圖案管理
* **批次上傳與自動分類**：可一次上傳多張小圖案，並根據檔名關鍵字（如 `blue`、`red`、`card` 等）自動對應車站屬性。
* **精簡橫向清單與微調**：以不佔空間的橫向並排顯示圖塊，支援即時修改名稱、切換屬性、單獨調整辨識門檻（Threshold）或刪除圖塊。

### 3. 🔍 大地圖上傳與 AI 自動辨識
* **地圖上傳**：支援上傳各種遊戲地圖圖片進行背景渲染與視覺化操作。
* **Y 軸向上網格編碼**：點擊執行後會自動進行像素比對、過濾重疊，並採用桃鐵標準的 **Y 軸向上遞增座標系統**（向上走 `gy+1`，向下走 `gy-1`）進行相對座標編碼。

### 4. 🎨 視覺化預覽與畫布縮放
* **即時節點檢視**：在畫布上直接標註車站外框、屬性標籤與網格座標 `(gx, gy)`。
* **縮放控制**：內建縮放滑桿（20% 至 300%）、即時百分比顯示與重置大小按鈕。

### 5. 📋 標準 JSON 輸出與靜默複製
* **即時生成數據**：自動將辨識結果轉為標準的 JSON 格式（包含區域、節點、阻擋等欄位）。
* **無干擾一鍵複製**：點擊按鈕即可將 JSON 數據複製到剪貼簿，並在按鈕旁顯示安靜的「已複製成功！✓」提示文字。
